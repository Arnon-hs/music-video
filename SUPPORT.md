# Support

Start with the [English guide](README.md) or [Russian guide](README.ru.md), then run:

```bash
./music-video doctor
./music-video genres
./music-video generate --backend <backend> --genre <genre> --duration 60 --dry-run
```

Use the bug-report template for a reproducible code problem and include redacted environment details. Use a feature request for new behavior. General support is best-effort and should stay in public issues so future users can find the answer.

Never post API keys, tokens, private media, personal data, model files, or confidential vulnerabilities. Follow `SECURITY.md` for security reports.
